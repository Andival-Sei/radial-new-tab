# Политика конфиденциальности Radial New Tab

Дата вступления в силу: 2 сентября 2026 года.

Radial New Tab не собирает аналитику, историю посещений, поисковые запросы или персональные данные и не управляет собственными серверами для обработки пользовательских данных.

Сохранённые ссылки и настройки хранятся средствами браузера в `chrome.storage.sync`, если синхронизация доступна, либо в `chrome.storage.local`. Эти данные доступны только расширению и инфраструктуре синхронизации браузера пользователя. Пользователь может экспортировать, импортировать и сбросить их в интерфейсе расширения.

Когда пользователь подтверждает поисковый запрос, расширение открывает выбранную поисковую систему (Microsoft Bing, Google или DuckDuckGo) и передаёт ей текст запроса в URL. Обработка запроса регулируется политикой конфиденциальности выбранной системы.

Иконки сохранённых сайтов запрашиваются через встроенный favicon API браузера. Расширение не содержит рекламы, трекеров и скрытых сетевых запросов.

По вопросам политики можно создать issue в GitHub-репозитории проекта.
