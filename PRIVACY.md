# Политика конфиденциальности Radial New Tab

Дата вступления в силу: 2 сентября 2026 года.

Radial New Tab не собирает аналитику, историю посещений, поисковые запросы или персональные данные и не управляет собственными серверами для обработки пользовательских данных.

Сохранённые ссылки и настройки хранятся средствами браузера в `chrome.storage.sync`, если синхронизация доступна, либо в `chrome.storage.local`. Эти данные доступны только расширению и инфраструктуре синхронизации браузера пользователя. Пользователь может экспортировать, импортировать и сбросить их в интерфейсе расширения. Выбранное фоновое изображение хранится отдельно в локальном хранилище устройства, потому что изображения не должны занимать квоту синхронизации, и не включается в JSON-экспорт.

Коллекции выключены по умолчанию. При включении пользователь может запустить импорт только выбранной папки закладок Edge или Chrome. Расширение читает дерево этой папки после явного разрешения `bookmarks`, превращает вложенные папки в коллекции и пропускает уже сохранённые URL. Содержимое закладок не отправляется на сервер Radial.

Функция автодобавления часто посещаемых сайтов выключена по умолчанию. После явного включения пользователь предоставляет опциональное разрешение `topSites`; расширение получает конечный список популярных URL, отбрасывает дубли доменов и добавляет его без обращения к серверам Radial. В режиме «Орбита» отображается компактное ядро первых ссылок, а «Умная плитка» позволяет просматривать весь импортированный список. Добавленные ссылки далее хранятся по общим правилам выбранного браузерного хранилища и при включённой синхронизации профиля могут передаваться инфраструктуре этого браузера. Разрешение можно отозвать на странице управления расширением.

Когда пользователь подтверждает поисковый запрос, расширение открывает выбранную поисковую систему (Google, Яндекс, Microsoft Bing или DuckDuckGo) и передаёт ей текст запроса в URL. При выборе «По умолчанию в браузере» запрос передаётся провайдеру, настроенному пользователем в Edge или Chrome, через API браузера. Обработка запроса регулируется политикой выбранной системы.

Иконки сохранённых сайтов сначала запрашиваются через встроенный favicon API браузера. Если сайт не отдаёт значок через этот API, расширение может запросить только его общедоступные адреса `/favicon.ico` и `/apple-touch-icon.png`, а затем передать домен (не полный путь) в Google S2 favicon для последней попытки получить значок. Расширение не содержит рекламы, трекеров и скрытых сетевых запросов.

По вопросам политики можно создать issue в GitHub-репозитории проекта.
