# Безопасность

Если вы обнаружили уязвимость, пожалуйста, не публикуйте её в открытом Issue.

Откройте приватный отчёт через **Security → Report a vulnerability** на GitHub. Если эта функция недоступна, свяжитесь с владельцем репозитория через профиль [Andival-Sei](https://github.com/Andival-Sei).

Обычные ошибки и предложения по улучшению публикуйте через [шаблоны Issues](https://github.com/Andival-Sei/radial-new-tab/issues/new/choose).
