# Участие в проекте

Баги и предложения принимаются через [Issues](https://github.com/Andival-Sei/radial-new-tab/issues/new/choose). Для повторяемых ошибок используйте шаблон **Баг — русский** или **Bug — English**, а для идей — соответствующий шаблон предложения.

Перед Pull Request выполните проверки:

```powershell
pnpm check
pnpm test
pnpm build
```

Изменения должны сохранять приватность расширения: пользовательские ссылки и настройки не отправляются на собственные серверы Radial.
