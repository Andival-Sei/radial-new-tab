# Radial New Tab

Спокойная и быстрая стартовая страница для Microsoft Edge и Chromium-браузеров. Любимые сайты располагаются на персональной орбите вокруг часов и поиска.

## Возможности

- автоматическая светлая/тёмная тема с ручным переключением;
- русский и английский интерфейс с автоопределением;
- поиск по сохранённым ссылкам через провайдера из настроек Edge/Chrome (по умолчанию), либо через Google, Яндекс, Bing или DuckDuckGo;
- добавление, редактирование, удаление и перетаскивание ссылок;
- опциональные коллекции: группы ссылок можно включить в настройках, переименовывать и удалять без потери самих ссылок;
- умный импорт выбранной папки закладок Edge/Chrome: вложенные папки становятся коллекциями, дубликаты URL пропускаются;
- два режима размещения: спокойная орбита и «Умная плитка», где часто открываемые ссылки постепенно получают больше места;
- опциональное автодобавление всего конечного списка популярных сайтов браузера через `chrome.topSites` (без дублей; в «Орбите» остаётся компактное ядро, а «Умная плитка» показывает весь список);
- собственное фоновое изображение до 5 МБ: оно хранится локально на устройстве и не перегружает синхронизацию настроек;
- синхронизация ссылок и настроек между устройствами в одном профиле Edge или Chrome через `chrome.storage.sync`, с локальным резервным хранением;
- импорт и экспорт данных;
- адаптивный интерфейс, клавиатурная навигация и reduced motion;
- Manifest V3 и минимальные разрешения: `storage`, `favicon`, `search`; разрешение `topSites` запрашивается только при включении автодобавления.

## Разработка на Windows 11

```powershell
pnpm install
pnpm dev
```

## Проверки

```powershell
pnpm check
pnpm test
pnpm build
pnpm test:ui
```

## Установка в Edge для тестирования

1. Выполните `pnpm build`.
2. Откройте `edge://extensions`.
3. Включите **Режим разработчика**.
4. Нажмите **Загрузить распакованное расширение** и выберите папку `dist`.

## Пакет для Edge Add-ons

```powershell
pnpm package
```

Готовый ZIP появится в `release/radial-new-tab-edge.zip`. Публикация в Edge Add-ons выполняется через Microsoft Partner Center.

## Конфиденциальность

Radial New Tab не собирает аналитику и не отправляет пользовательские данные на собственные серверы. Ссылки и настройки хранятся средствами браузера. При включённой синхронизации одного профиля Edge или Chrome они передаются средствами этого браузера на другие устройства с тем же профилем. Поисковый запрос передаётся только выбранной поисковой системе после подтверждения пользователем.

Для разных аккаунтов Edge и Chrome доступен безопасный перенос через уже встроенный экспорт и импорт. Прямая синхронизация через Google Drive потребует отдельного OAuth-подключения к Google и явного согласия пользователя — она намеренно не включена без этого подключения.
