# Radial New Tab — материалы магазина

Обновлено: 2026-11-16. Версия: 0.3.1.

Текущий канал публикации — **Microsoft Edge Add-ons**. Публикация в Chrome Web Store не выполнялась и не входит в этот выпуск. Подробные тексты карточки: [EDGE_STORE.md](docs/EDGE_STORE.md).

## Карточка

Название: Radial New Tab. Категория: Productivity. Основной язык: English; также доступен русский.

Краткие описания соответствуют `public/_locales/en/messages.json` и `public/_locales/ru/messages.json`:

EN: Calm Edge new tab with shortcuts, collections, search, smart tiles, themes, and optional bookmark import.

RU: Спокойная новая вкладка Edge: ссылки, коллекции, поиск, умная плитка, темы и импорт закладок.

Единственная задача: персональная новая вкладка для управления часто используемыми ссылками и поиска в интернете.

## Разрешения

| Разрешение | Тип | Назначение |
|---|---|---|
| `storage` | Обязательное | Сохранение ссылок, настроек и агрегированной статистики; синхронизация профиля и локальная резервная копия. |
| `favicon` | Обязательное | Значки сохранённых сайтов из кеша браузера. |
| `search` | Обязательное | Поиск по подтверждённому запросу через поисковую систему браузера. |
| `topSites` | Опциональное | Выбор или автодобавление популярных сайтов после явного разрешения. |
| `bookmarks` | Опциональное | Импорт выбранной папки закладок и вложенных папок после явного разрешения. |

`host_permissions` и удалённого исполняемого кода нет.

## Данные и конфиденциальность

Данные не отправляются разработчику, не продаются и не используются для рекламы или оценки кредитоспособности. Аналитики нет. Ссылки, настройки, коллекции и агрегированные открытия обрабатываются локально и могут передаваться инфраструктурой синхронизации профиля браузера. Фон остаётся на устройстве. Поисковая система получает подтверждённый запрос; сайты и Google S2 могут получать запросы иконок с доменом ссылки. Полная история посещений не запрашивается и не сохраняется.

## Выпуски и готовность

0.3.1 — обновлённое оформление, доступность, клавиатурное управление, проверенный импорт и хранение больших библиотек. Подробности и проверки: [RELEASE_0.3.1.md](docs/RELEASE_0.3.1.md).

`pnpm package` собирает только `dist/`: исходники, конфигурация, тесты, зависимости и секреты в ZIP не входят. Изображения и тексты карточки подготовлены отдельно: Publish API отправляет только пакет. Фактический результат отправки хранится в GitHub Actions, artifact `edge-publication-status`; успешная отправка не означает одобрение Microsoft.
