# Radial New Tab 0.3.1

16 ноября 2026 года.

- Обновлены светлая и тёмная темы, знак Radial, фон, отступы и оформление плиток.
- Сетка сохраняет читаемый размер ссылок. Большая библиотека на маленьком экране прокручивается; 24 ссылки помещаются в окно 1280×720.
- Ссылки можно переставлять клавишами Alt + стрелки. Перетаскивание сохраняет закрепление.
- Меню добавления управляется клавишами и закрывается по клику снаружи. Название действия с популярными сайтами теперь соответствует данным браузера.
- Окна доступны на низких экранах, удерживают фокус и возвращают его к вызвавшей кнопке; элементы под открытым окном недоступны для случайного нажатия.
- Импорт проверяет настройки, URL, коллекции и статистику, ограничивает размер файла и запрашивает подтверждение замены данных.
- Большие библиотеки синхронизируются частями с сохранением последней полной копии. При недоступной синхронизации настройки объясняют, что данные сохранены локально.
- Открытые вкладки подхватывают изменения ссылок и настроек. Часы обновляются на границе минуты или секунды, отдельно от всей библиотеки.
- Код разделён на модули хранения, закладок, сетки и компонентов. Версии зависимостей зафиксированы, известные уязвимости устранены, форматирование проверяется автоматически.
- CI запускает браузерные тесты и проверку настоящего распакованного расширения. Проверяются также PNG-иконки и пакет публикации.

Новых разрешений нет. Аналитика и серверная часть отсутствуют. Фоновое изображение остаётся локальным и не включается в JSON-экспорт.

## Проверка выпуска

`pnpm check`, 17 модульных тестов, 2 теста публикации, 22 браузерных сценария, `pnpm package`, `pnpm audit`.
Браузерные сценарии включают запуск Manifest V3 как настоящего расширения Chromium с реальным хранилищем.

## Ограничения

Синхронизация профиля контролируется браузером; тесты не подтверждают доставку данных между физическими устройствами. Одновременные изменения одной библиотеки на разных устройствах разрешаются по последней сохранённой копии. Для безопасной замены снимка резервируется место в квоте: при сериализованном объёме более 45 КБ используется локальное хранение. Обновите расширение на всех устройствах перед редактированием большой библиотеки.

Закреплён scoped override `@typescript-eslint/typescript-estree>minimatch` версии 11.0.8 для исправления glob amplification DoS в инструментах разработки. Используемый upstream вызов `minimatch(path, pattern, { dot: true })` совместим; типы и lint проверены. Override можно убрать после перехода upstream на исправленную ветку.

GitHub Release запускает отправку пакета на сертификацию Microsoft. Одобрение и распространение обновления зависят от магазина. Описание и изображения карточки API пакетов не обновляет; актуальные материалы сохранены в `docs/edge-store/`.

Исправлена воспроизводимость форматирования на Windows runner: `.gitattributes` сохраняет LF независимо от `core.autocrlf`. Выпуск 0.3.0 остановился на этой проверке и в магазин не отправлялся.

## Отправка в магазин

16 ноября 2026 года версия 0.3.1 отправлена на сертификацию через Partner Center. Кабинет подтвердил статус **«Проверяется»**; указан срок ответа до 7 рабочих дней. До одобрения в магазине остаётся версия 0.2.1.

Обновлены русское и английское описания, четыре скриншота и обе рекламные плитки. [GitHub Release с проверенным ZIP](https://github.com/Andival-Sei/radial-new-tab/releases/tag/v0.3.1).

Автоматическая отправка в GitHub Actions получила HTTP 401 до загрузки. В тот же день истёкший ключ продлён и доступ к Publish API восстановлен, что проверено отдельным GET из GitHub Actions. Последующие выпуски используют API; повторная отправка 0.3.1 не требуется. Порядок работы — в `RELEASE_AUTOMATION.md`.
