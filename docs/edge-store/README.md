# Материалы для Microsoft Edge Add-ons

Готовые материалы для карточки Radial New Tab в Partner Center:

- `small-promotional-tile-440x280.png` — маленькая рекламная плитка;
- `large-promotional-tile-1400x560.png` — большая рекламная плитка;
- `screenshot-orbit-1280x800.png` — основной экран с орбитальными ссылками;
- `screenshot-settings-1280x800.png` — настройки внешнего вида, языка и поисковика;
- `screenshot-smart-tiles-1280x800.png` — режим умных плиток;
- `source-radial-background.png` — исходный фон для будущих вариантов.

PNG-файлы уже имеют размеры, которые указаны в форме загрузки Edge Add-ons. Скриншоты показывают реальный интерфейс расширения, а не макет.

Перегенерация выполняется командой `pnpm capture:store` при запущенном локальном preview-сервере на `http://127.0.0.1:4173`.
