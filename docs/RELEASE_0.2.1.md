# Radial New Tab 0.2.1

- Добавлено быстрое добавление сайтов из недавнего списка браузера без открытия редактора.
- Нижняя панель действий перенесена вправо, удалены дублирующие действия и приветственная подпись.
- Сетка плиток динамически подбирает число колонок и плотность, чтобы большая библиотека ссылок помещалась в окно.
- Обновлены store-скриншоты и рекламные изображения.

Новые обязательные разрешения не добавлены. Отправка обновления в Microsoft Edge Add-ons проходит через автоматическую сертификацию.
