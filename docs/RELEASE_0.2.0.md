# Radial New Tab 0.2.0

- Только плитка: орбита удалена, существующие ссылки и настройки мигрируют автоматически.
- Новый спокойный светлый и графитовый интерфейс, ровная сетка, адаптация к узким окнам.
- Сохранённые ссылки не меняют места из-за статистики. Отдельные рекомендации учитывают недавность, частоту, время суток и день недели; старые привычки постепенно теряют вес.
- Закрепление важных ссылок, отмена удаления, поиск с выбором стрелками и Enter.
- Более надёжное локальное резервирование при переполнении синхронизации, проверка импортируемых URL и статистики.
- Улучшена клавиатурная доступность диалогов и видимость фокуса.
- GitHub Release запускает проверки, сборку и отправку в Microsoft Edge Add-ons на сертификацию.

Новые обязательные разрешения не добавлены. Одобрение Microsoft и распространение обновления происходят отдельно от GitHub Release.
